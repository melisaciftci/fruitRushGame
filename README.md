# 🍓 Fruit Rush 🍇🍋🍎

Fruit Rush is a prototype game inspired by the classic Candy Crush Saga. It is developed using the C programming language, with graphical operations powered by the Raylib library. This project was prepared as part of the CEN-118 Algorithms and Programming Lab II course at Çukurova University, Department of Computer Engineering (1st year).

The game aims to provide an enjoyable gaming experience with its colorful graphics, fun music, and unique design. The game includes different levels with specific tasks, such as reaching a certain score or completing objectives within a limited number of moves.

## 🎮 Game Features
- 🍒 4 different fruit symbols
- 🍏 Match 3, 4, or 5 of the same fruits horizontally or vertically to earn points
- 🌿 Special item “Cookie” created upon matching 5 fruits
- 💡 Various levels and task-based progression
- 🔢 Move counter and score tracking system
- 🏆 High score system
- 🎵 Background music and sound effects
- 🎨 Animations and interactive transition screens
- 🎉 Start, end, win, and lose screens

## 🛠 Installation
1. Clone this repository:
    ```bash
    git clone https://github.com/username/fruit_rush.git
    ```
2. Install the Raylib library: [Raylib Installation](https://www.raylib.com/)
3. Compile the project in your terminal:
    ```bash
    gcc main.c -o fruit_rush -lraylib -lm
    ```
4. Run the game:
    ```bash
    ./fruit_rush
    ```

## 🕹 How to Play
- Align at least three identical fruits horizontally or vertically to collect points.
- Create the special "Cookie" fruit to clear surrounding fruits.
- Complete the level objectives before running out of moves.
